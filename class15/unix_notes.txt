Process control
^C ctrl + C: kills a running job
^Z ctrl + Z: suspends a running job, temporarily pauses; allows you to send it to background or foreground
top: displays the top running processes
kill PID. kill a job with this PID number
&: if you put an & at the end of a code line, it will run the process in the background
    - e.g. blastp -query mm-second.fa -db zebrafish.1.protein.faa -out my_results_zebrafish2.tsv -outfmt 6 &
